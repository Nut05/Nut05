## Featured Projects

### 📱 PhoneHub – Phone Store Management & Sales App

A desktop app for a phone and accessories store: in-store sales, online orders, IMEI-based inventory, returns, warranty, business reports, and an AI assistant, with 5 user roles.

**Role:** Team Leader, Business Analyst & Developer  
**Tech Stack:** C# / .NET, WinUI 3, MVVM, Node.js / Express, PostgreSQL (Supabase)

**Key Contributions:**

* Led a team of 4: split tasks, tracked progress, and set up project docs and coding guidelines
* Wrote the **business analysis document**: user roles and permissions, business rules, main processes, order status flow, and the feature list
* Wrote the **database design document** and **ERD**, plus demo data scenarios for testing
* Built API endpoints for the customer cart, checkout, accounts, and online orders
* Moved admin screens to **MVVM** and redesigned the admin UI with form validation

**Repository:** 🔒 Private

---

### 🛒 BI System with Generative AI – Olist E-commerce

An end-to-end Business Intelligence system on the Brazilian **Olist e-commerce** dataset, from raw CSV files to Power BI dashboards with AI-generated insights.

**Role:** Business Analyst & Data Modeler  
**Tech Stack:** PostgreSQL, dbt, Mage.ai, Docker, Power BI

**Key Contributions:**

* Defined **business questions, KPIs, and analysis requirements** for each business process
* Wrote the **source-to-target mapping** for the reporting data model
* Built **dbt** models from staging to dimension and fact tables
* Sketched dashboard layouts and built the **Seller analysis page** in Power BI

**Repository:** 🔒 Private

---

### 🏠 HomeStayDorm – Dormitory Rental Management System

A web system for managing dormitory and homestay rentals: deposits, rental contracts, residence approval, check-in payments, and room handover (System Analysis & Design course).

**Role:** Analyst & Full-stack Developer  
**Tech Stack:** ReactJS, Node.js / Express, SQL Server

**Key Contributions:**

* Wrote the **use case specification** for rental contracts and documented the payment calculation rules
* Built the rental contract, check-in payment, and room handover features
* Wrote **SQL Server stored procedures** for contracts, deposits, payments, and handover rules, including shared-room cases

**Repository:** [NhatVy177/HomeStayDorm](https://github.com/NhatVy177/HomeStayDorm)
